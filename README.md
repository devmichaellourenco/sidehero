# sidehero

Extensão Chrome **Side Hero** — idle RPG no painel lateral do navegador.

## Desenvolvimento

```bash
npm install --cache ./.npm-cache
npm run build
```

Carregue a pasta `dist/` em `chrome://extensions` (modo desenvolvedor).

- `step-by-step/` — histórico de desenvolvimento
