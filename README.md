# sidehero

Extensão Chrome **Side Hero** — idle RPG no painel lateral do navegador.

## Desenvolvimento

```bash
npm install --cache ./.npm-cache
npm run build
```

Carregue a pasta `dist/` em `chrome://extensions` (modo desenvolvedor).

## Histórico de desenvolvimento

- `specs/` — specs SDD por feature (fonte de verdade)
- `.cursor/AGENTS.md` — agents, skills e rules do projeto
- `releases/` — notas e zips de versão publicada
